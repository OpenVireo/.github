<h3 align="center">OpenVireo</h3>

<p align="center">
  A free, open-source password manager with end-to-end encrypted sync.<br>
  Desktop, web, iPhone and iPad, and your browser. KeePass-compatible.
</p>

---

Your vault is encrypted on your device before it is synced, so the server only ever stores ciphertext. Vaults stay in the open KDBX format, so you can export them and open them in any KeePass client.

### Repositories

The pinned repositories below hold the desktop app ([openvireo](https://github.com/OpenVireo/openvireo), a fork of [KeePassXC](https://keepassxc.org)), the browser extension, the SDK and `ov` CLI, and the sync server. The source for [openvireo.com](https://openvireo.com) is in [openvireo-site](https://github.com/OpenVireo/openvireo-site).

### Get it

- **Desktop:** [openvireo.com/download](https://openvireo.com/download/) or [GitHub releases](https://github.com/OpenVireo/openvireo/releases). Releases are signed ([how to verify](https://openvireo.com/verifying-signatures/)).
- **iPhone and iPad:** [App Store](https://apps.apple.com/app/id6832415350)
- **Browser:** [openvireo.com/download](https://openvireo.com/download/) (Chrome, Firefox and Edge)
- **Developers:** [SDK docs](https://openvireo.com/docs/sdk/) · [Sync server docs](https://openvireo.com/docs/sync-server/)

### Security

Please report vulnerabilities privately through a [GitHub security advisory](https://github.com/OpenVireo/openvireo/security/advisories/new), or email [admin@openvireo.com](mailto:admin@openvireo.com) with "Security" in the subject. Please don't open public issues for them.
